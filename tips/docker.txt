1. Посмотреть работающие контейнеры:
docker ps

2. Посмотреть вообще все контейнеры:
docker ps -a

3. Cписок закешированных образов, что можно запускать
docker image ls

4. Запустить контейнер
docker run -it

5. Зайти в запущенный контейнер
docker exec -it -u 0 container - зайти рутом
docker exec -it container - зайти дефолтным пользователем
